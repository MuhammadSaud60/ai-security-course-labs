===========

                     every call logged     only fake files

Fence: paths under /sandbox/ only
Allowlist: read_file, write_file
Blocked by default: delete_file, send_email
Rule: a tool runs only if it is on the allowlist AND its path
is inside the fence. Everything else is blocked and logged.

Tools:
  read_file    [ALLOWED] reads a fake file
  write_file   [ALLOWED] writes a fake file
  delete_file  [BLOCKED] deletes a fake file, final
  send_email   [BLOCKED] sends an email out
